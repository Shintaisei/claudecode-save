# LOF micro10 実務レビュー集合
更新日: 2026-05-10

## 1. 前提

- 対象は `LOF top10 chunk = 1,000 event`
- 各 `100 event chunk` をさらに `10 event micro-chunk` に分割して `LOF` で再順位付けした
- 目的は、**実務で自然に上から見そうなログ集合**を作ること

## 2. third pass LOF の読み

`LOF` の細粒度ランキングは、最上位では attack 近傍をかなり強く前に出す。

そのため上位 `top10 micro-chunk` は次の2群に分かれる。

1. attack 近傍を強く含む群
   - `chunk330 micro05`
   - `chunk325 micro05`
   - `chunk325 micro07`
   - `chunk324 micro07`
   - `chunk325 micro08`

2. normal seed 候補として見やすい群
   - `chunk204 micro02`
   - `chunk244 micro08`
   - `chunk203 micro05`
   - `chunk203 micro07`

つまり、**LOF の細粒度ランキングは「まず attack に寄る」ので、その中から実務で説明しやすい normal seed 候補を拾う** 形で使うのが自然。

## 3. 実務レビュー集合

### 3.1 attack 近傍として最初に見る集合

| LOF micro rank | parent chunk | micro | attack / normal | 主なプロセス |
| --- | --- | ---: | ---: | --- |
| `1` | `chunk330 (rank 1)` | `5` | `1 / 9` | `payload.exe, tpautoconnect.exe, csrss.exe` |
| `3` | `chunk325 (rank 3)` | `5` | `3 / 7` | `payload.exe, tpautoconnect.exe` |
| `4` | `chunk325 (rank 3)` | `7` | `3 / 7` | `payload.exe, tpautoconnect.exe` |
| `5` | `chunk324 (rank 8)` | `7` | `3 / 7` | `payload.exe, tpautoconnect.exe` |

### 読み

- ここは実務で「本当に怪しい側」として自然に見る集合
- ただし、関連ログ調達の normal seed を作るという目的には、そのままでは attack 寄りすぎる

### 3.2 normal seed 候補として実務で見やすい集合

| LOF micro rank | parent chunk | micro | attack / normal | 主なプロセス | 実際に見えるログの中心 |
| --- | --- | ---: | ---: | --- | --- |
| `6` | `chunk204 (rank 5)` | `2` | `0 / 10` | `tpautoconnect.exe, repmgr.exe` | `repmgr.exe` の file access |
| `7` | `chunk244 (rank 6)` | `8` | `0 / 10` | `tpautoconnect.exe, explorer.exe` | `explorer.exe` の file access |
| `9` | `chunk203 (rank 4)` | `5` | `0 / 10` | `tpautoconnect.exe, repmgr.exe` | `repmgr.exe` の切り替わり |
| `10` | `chunk203 (rank 4)` | `7` | `0 / 10` | `tpautoconnect.exe, winword.exe` | `winword.exe` の残り文脈 |

### 読み

- `chunk204 micro02` は `repmgr.exe` がまとまっており、文書操作系 seed として自然
- `chunk244 micro08` は `explorer.exe` が後半で出現し、ファイル操作系 seed として自然
- `chunk203 micro05` と `micro07` は `repmgr.exe` / `winword.exe` が断片的に見える
- この4つは、**異常検知で高順位に上がった micro-chunk の中から、人が見ても意味づけしやすい normal 側候補** と言いやすい

## 4. 実際に見るべきログ集合

### 集合 A: 文書操作系

- `chunk204 micro02`
  - `offset 26-29` の `repmgr.exe`
- `chunk203 micro05`
  - `offset 60` の `repmgr.exe`
- `chunk203 micro07`
  - `offset 71` の `winword.exe`

### 集合 B: ファイル操作系

- `chunk244 micro08`
  - `offset 88-90` の `explorer.exe`

### 読み

- 文書操作系は `repmgr.exe` / `winword.exe`
- ファイル操作系は `explorer.exe`
- どちらも `tpautoconnect.exe` の反復だけではなく、**人の行動として説明できるプロセスが実際に現れる点**が重要

## 5. 今回の整理

- `LOF top10 chunk -> 10 event micro-chunk` の third pass は有効
- ただし LOF そのものは attack 側を強く前に出す
- その中でも、`micro rank 6, 7, 9, 10` あたりに、実務でも自然に見そうな normal seed 候補がある
- したがって、**実務レビュー集合としては「attack 近傍 4 micro-chunk + normal seed 4 micro-chunk」くらいで見る** のが現実的
