# CERT Insider Threat Dataset 調査メモ
> 作成日: 2026-04-16  
> 目的: 正常業務行動データセットとして CERT Insider Threat Dataset が研究目的に合うか確認する。

---

## 1. 概要

CERT Insider Threat Dataset は、CMU SEI / CERT Division が公開しているインサイダー脅威検知用の合成データセットである。

公開ページ上では、背景となる通常行動データと、悪性内部者の行動データを含む合成データセットとして説明されている。

本研究の観点では、APT-Persistence のような EVTX / Sysmon ログではなく、組織内ユーザーの業務行動を抽象化した CSV ログとして見るのがよい。

## 4. CSV形式

### logon.csv

フィールド:

```text
id,date,user,pc,activity
```

例:

```text
{Y6O4-A7KC67IN-0899AOZK},01/04/2010 00:10:37,DTAA/KEE0997,PC-1914,Logon
```

意味:

- いつ
- どのユーザーが
- どのPCに
- ログオン/ログオフしたか

### device.csv

フィールド:

```text
id,date,user,pc,activity
```

例:

```text
{S7A7-Y8QZ65MW-8738SAZP},01/04/2010 07:12:31,DTAA/RES0962,PC-3736,Connect
```

意味:

- USBなどのリムーバブルデバイス接続/切断

### http.csv

フィールドはREADME上では以下と説明されている。

```text
id,date,user,pc,url
```

例:

```text
{M8H9-W9NL75TH-1322KOLO},01/04/2010 07:08:47,DTAA/AMA0606,PC-1514,"http://cnet.com"
```

意味:

- いつ
- 誰が
- どのPCから
- どのURLを見たか

### LDAP

フィールド:

```text
employee_name,user_id,Domain,Email,Role
```

例:

```text
Burton M Stephenson,BMS0001,dtaa.com,Burton.M.Stephenson@dtaa.com,Security
```

意味:

- ユーザーID
- 所属ドメイン
- メール
- 役職
- 月末時点での在籍者

## 5. 正解ラベル

`answers.tar.bz2` には悪性行動の正解情報が含まれる。

主な構成:

```text
answers/
├── insiders.csv
├── scenarios.txt
├── r2.csv
├── r3.1-1.csv
├── ...
└── r4.2-1/
```

`insiders.csv` は、データセット、シナリオ番号、詳細ファイル、ユーザー、開始時刻、終了時刻を持つ。

シナリオ例:

| シナリオ | 内容 |
|---:|---|
| 1 | 普段USBや時間外勤務をしないユーザーが、時間外ログオン、USB利用、wikileaks.orgへのアップロードを行い、その後退職 |
| 2 | 求人サイト閲覧や競合への接触後、退職前にUSBでデータ窃取 |
| 3 | 不満を持つ管理者がキーロガーを仕込み、上司アカウントで不審メール送信 |
| 4 | 他人の端末にログインし、ファイル探索して個人メールへ送信 |
| 5 | レイオフ対象グループのメンバーがDropboxへ文書アップロード |

## 6. 研究目的との相性

### 強い点

- 正常な業務行動の時系列を大量に含む
- ログオン、Web閲覧、USB利用、組織情報を扱える
- 悪性シナリオの正解ラベルがある
- 正常行動から逸脱した行動を扱う研究にはかなり使いやすい
- 「通常業務の文脈から怪しい行動を判断する」という研究とは相性がよい

### 弱い点

- EVTXではない
- Sysmonではない
- Windowsプロセス親子関係やコマンドラインはない
- Hayabusaには直接かけられない
- URLやユーザー行動は合成・抽象化されている
- r1ではメールやファイル操作ログがなく、後続リリースの方が有用な可能性が高い

---

## 7. 本研究での位置づけ

CERT Insider Threat Dataset は、APT-Persistence の代替というより、研究背景・比較対象として使うのがよい。

使い方の候補:

1. 正常業務行動データセットの代表例として紹介する
2. 「業務文脈は豊富だがEVTXではない」例として、Hayabusa実験に使いにくい理由を説明する
3. 自前収集の必要性を補強する
4. 将来的に、行動復元の出力形式だけをCERTに適用して評価する

本研究の現在の目的が「起点アラートからEVTX/Sysmonをたどって正常行動を復元する」なら、CERTはそのまま主データにはしにくい。

ただし、目的を「正常業務文脈から異常/正常の判断根拠を構造化する」まで広げるなら、CERTはかなり有力な比較データになる。

---

## 8. 一言でいうと

CERT Insider Threat Dataset は、正常業務行動の研究ではかなり定番に近いデータセットである。

ただし、データ形式は WindowsイベントログではなくCSVであり、Hayabusaにそのままかけるデータではない。

したがって、本研究では「正常業務行動データセットとしては有力だが、EVTX起点の行動復元実験には直接使いにくい」という位置づけが妥当である。
