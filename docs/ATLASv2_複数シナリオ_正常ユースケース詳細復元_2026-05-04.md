# ATLAS v2 複数シナリオ 正常ユースケース詳細復元

作成日: 2026-05-04

## 1. この段階でやりたいこと

前段の整理で、`M4 / M6 / S4 / M5` が正常ユースケース候補として有望だと分かった。  
ここでは、最終候補として残った normal seed から

- どんな行動が復元できるか
- 研究分類のどこへ置けるか
- どの scenario を主ケースにするべきか

をもう一段具体化する。

今回見るのは `Security` ログ上の event template なので、復元できるのは `ファイルアクセス主体の行動輪郭` である。  
特に多いのは次の triad である。

- `4656`: file object への handle 要求
- `4663`: file object への実アクセス
- `4658`: handle close

したがって、ここでの「行動復元」は、`どの process がどの塊で継続的に file access していたか` を中心に読む。

## 2. 先に結論

今回の正常ユースケース候補は、かなり素直に4種類へ分けられる。

1. `M4`
   `Excel + MMC + Consent` の業務操作・管理操作
2. `M6`
   `Excel + WMI` の業務操作と背景管理の混成
3. `S4`
   `upd.exe + scanhost.exe + wmiapsrv.exe` の背景動作
4. `M5`
   `PowerShell` 主体の attack-near procedural context

このうち、研究の主役に一番向くのは `M4` である。  
理由は、`業務操作っぽさが強い`, `100% normal`, `説明しやすい`, `他 scenario と比較しやすい` の4点である。

`M6` はその次に強く、`Office 文脈に背景管理が混ざる` ので補助ケースとしてよい。  
`S4` は pure normal だがユーザ操作感が弱く、背景動作型の対照ケースとして使うのがよい。  
`M5` は pure normal ではないが、`正常寄りの境界ケース` として価値が高い。

## 7. 研究分類としてどう落とすか

今回の4 scenario を研究分類へ落とすと、次のように整理できる。

| Scenario | 主体 process | 復元される行動 | 行動型 | 判定 | 研究上の役割 |
| --- | --- | --- | --- | --- | --- |
| M4 | `excel.exe`, `mmc.exe`, `consent.exe` | 業務ファイル操作 + 管理操作 | 単発操作型〜手続型 | 正常 | 主ケース |
| M6 | `excel.exe`, `wmiapsrv.exe` | 業務操作 + 背景管理 | 手続型 + 背景動作型 | 正常 | 副ケース |
| S4 | `upd.exe`, `scanhost.exe`, `wmiapsrv.exe` | 更新・スキャン・管理 | 背景動作型 | 正常 | 対照ケース |
| M5 | `powershell.exe` | PowerShell 連続処理 | 手続型 | 正常寄り | 境界ケース |

この形にすると、

- `正常そのもの`
- `正常だが背景動作寄り`
- `正常寄りの境界`

をそれぞれ別の scenario で押さえられる。

## 8. 今回の目的に対する最終提案

今回の目的が `正常のユースケースを作ること` なら、最終的な使い方は次が一番よい。

1. `主ケース`
   `M4`
   業務アプリと管理操作が見えるので、最も説明しやすい正常行動
2. `副ケース`
   `M6`
   実環境らしい混成文脈を足せる
3. `対照ケース`
   `S4`
   背景動作型の純正常群として使える
4. `境界ケース`
   `M5`
   normal ratio は高いが完全に clean ではない手続型ケース

この構成にすると、研究で

- 典型的な正常業務
- 背景で自然に起きる正常処理
- 攻撃近傍でも残る正常寄り文脈

の3層を揃えられる。

## 9. ここまでで言えること

ここまでの分析から、次のことはかなり強く言える。

1. `M4 / M6 / S4` では、最終候補として残った seed は実質 pure normal である
2. `M4` は Office/管理操作の正常ユースケースとして最も扱いやすい
3. `M6` は混成文脈を与えるので、M4 だけでは弱い実環境らしさを補える
4. `S4` は背景動作型の正常ベースラインとして価値が高い
5. `M5` は pure normal ではないが、attack-near normal context の代表例として有用である

したがって、正常ユースケース研究としては、

- `M4` を中心に据える
- `M6` と `S4` で幅を持たせる
- `M5` を境界ケースとして添える

という設計で十分説得力を持たせられる。
