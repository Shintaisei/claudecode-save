# second pass の異常スコアはどれくらい差があるか

## 1. 目的

second pass では各 `100 event chunk` に対して異常スコアを出し、  
そのスコア順に review 対象を並べている。

ここでは、

- 上位 chunk 同士でどれくらいスコア差があるか
- attack を含む chunk が、上位の中でどこに入っているか

を見える形で整理する。

対象は有力候補の

- `LOF`
- `OneClassSVM`

の 2 手法とする。

## 2. 見方

raw score は手法ごとに意味もスケールも違うため、  
今回は次の 2 つで見る。

1. **閾値との差**
   - `score - threshold`
   - threshold をどれだけ上回っているか
2. **top10 内正規化順位**
   - `top1 = 1.00`
   - `top10 = 0.00`
   - 上位 10 件の中でどれだけ差があるか

## 5. まとめ

### 5.1 LOF

- 上位 3 件に attack が入りやすい
- top3 まででも seed 候補として強い
- ただし raw score は極端に大きく、絶対値そのものの解釈は難しい

### 5.2 OneClassSVM

- top1 は外すが、top2 で attack に到達
- top6〜top8 に attack が厚い chunk がまとまる
- 「最小 seed」より「少し厚めに見る」用途に向く

## 6. 発表向けの言い方

「異常スコアの大きさを見ると、LOF は上位 3 件に attack chunk が集中しやすく、seed 抽出に向く。一方、OneClassSVM は top1 では外すことがあるが、top6〜top8 に attack がまとまって現れるため、少し広めに確認する運用に向く。」
