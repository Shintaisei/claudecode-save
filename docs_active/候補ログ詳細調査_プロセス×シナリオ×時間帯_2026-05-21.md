# 候補ログ詳細調査：プロセス × シナリオ × 時間帯

作成日: 2026-05-21  
対象: ATLASv2 thirdpass kNN review100 の各シナリオ最終100ログ

---

## データ構造メモ

- `parent_session_id` 末尾タイムスタンプ = 10分単位のセッション窓（例: `20220719T1420Z` = 2022-07-19 14:20 UTC）
- `coarse_chunk_index` = secondpass 100イベント単位チャンクの全ログ中絶対インデックス
- `template` はイベントテンプレート文字列。**ObjectName（実ファイルパス）は含まれない**
- `label=1` = REAPr ground truth による攻撃ラベル
