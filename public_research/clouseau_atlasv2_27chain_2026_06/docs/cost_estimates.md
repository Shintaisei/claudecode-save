# Cost estimates

The conservative cost table is stored at:

- `results/cost_estimates_conservative.csv`

The table reports:

- one full loop = 81 runs,
- one chain = 3 runs,
- one run = one stage for one chain.

Reasoning-effort variants use the conservative assumption used during planning:

- default: billed output approximately equals visible output,
- medium: billed output about 2x visible output,
- high: billed output about 4x visible output.

These are planning estimates, not invoices. Verify current provider pricing before running additional model sweeps.
